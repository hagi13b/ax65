| 版 | 日付 | 内容 |
|---|---|---|
| ドラフト1 | 2026-10-28 | 議題 1〜7（型と演算、変数と記憶域、関数と呼び出し規約、配列とポインタ、I/O と割り込み、制御構文、列挙型と文字・文字列）の決定事項をまとめた |
| ドラフト2 | 2026-10-29 | 議題 8〜12（演算の細部、コンパイル時の計算、モジュール、インラインアセンブリ、ターゲット定義と出力）を追加。サンプル meteor の性能比較の結果を反映（読み捨ての I/O に `bit`、初期値 0 は `stz`、ポインタの引数をレジスタで渡す、展開の指定、最適化の段階） |
| ドラフト3 | 2026-10-29 | 章の番号を整理した。Q&A を付録にした |
| ドラフト4 | 2026-10-29 | 仮の仕様 5 点を決定（`irq_enable`、値を返す `atomic`、`let _ =`、BCD のリテラル、割り込み処理の中の `atomic` の省略） |
| ドラフト5 | 2026-10-29 | 古い版で書いたソースから見つかった 8 点を決定（書き込む側が 1 つの `shared`、`io_span`、配列と構造体の値、`as char`、変数の範囲の `for`、`&BUF`、`match` の腕、変換表の書式とエスケープ） |

| ドラフト7 | 2026-10-29 | 章立てを一般的な言語仕様書の形に組み直し、すべての仕様に例を付けた。コマンドラインのオプション、プロジェクトファイル、ターゲット定義の項目を全て明示した。Q&A を書き直した |
| **1.0** | 2026-10-29 | ドラフト7 から、次の点を変えた。Rust から借りて意味の薄かった仕様の整理（`let mut`・引数の `mut` の廃止、書き換えない `static` の廃止と `const` への統合、`static mut` を `static` に、`impl` の中の `pub`・`bits()`・`from_bits()`・`mut` 以外の予約語の廃止。[K-14](#qa-k14)〜[K-16](#qa-k16)、[M-10](#qa-m10)、[M-11](#qa-m11)）。`pure fn` を `const fn` に変更（[K-17](#qa-k17)）。見直しで見つかった食い違いの修正と規則の追加（保証の対象外の一覧、`shared` の 1 命令の操作と NMI の規則、関数を呼べる文脈、アドレスの持ち出し、割る数の型 `Nz8`・`Nz16`、BCD の変換の関数、`as` の範囲の検査、型を書かない `let` の整数リテラル、戻り値の返し方の表、資源の検査と最適化の段階、自動の逆順化と不要な書き込みの削除の条件、標準ライブラリの名前と `mul` インターフェース、`--deny-warnings`、レポートの項目。[M-1](#qa-m1)〜[M-20](#qa-m20)）。付録D を追加 |

ドラフト7 と 1.0 で、次の点を明文化しました（それまでのドラフトに書かれていなかったもの）。

- キーワードの一覧（[2.4節](#s2-4)）、演算子の優先順位（[5.1節](#s5-1)）、文法の要約（[付録A](#appA)）
- `u8 - i8 → u8` を `u8 + i8` と同じ例外にした（[3.1節](#s3-1)）
- 0 終端・最上位ビット終端の文字列の型名 `zstr`・`histr`、`strbuf` の操作（[3.9節](#s3-9)）
- ビットフラグと整数の `as` による変換（[3.6節](#s3-6)）、型の変換の一覧（[3.14節](#s3-14)）
- I/O の配列（[11.1節](#s11-1)）、`region` に複数の範囲を書く形と `extends` での置き換えの規則（[16.1節](#s16-1)、[16.3節](#s16-3)）
- bind されていないインターフェースの宣言は構文だけを検査すること（[8.4節](#s8-4)）
- `break` で値を返す `loop`（[6.3節](#s6-3)）、使っていない `bool`・`Option` の値の警告（[6.1節](#s6-1)、[18.2節](#s18-2)）
- 配列・文字列・構造体の `const` がアドレスを持つこと（[4.2節](#s4-2)）
- エラー番号の範囲と警告の名前の一覧（[18章](#s18)）、コマンドとオプションの全一覧（[17.4節](#s17-4)、[17.5節](#s17-5)）、プロジェクトファイルとターゲット定義の全項目（[17.2節](#s17-2)、[16.2節](#s16-2)）
- モジュールの探し方（[17.3節](#s17-3)）、標準ライブラリの一覧（[20章](#s20)）
