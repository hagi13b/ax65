# AX65 言語仕様書 1.0

AX65 は、自作 6502 マシン専用のプログラミング言語です。コンパイラの名前は ax65 です。

| 項目 | 内容 |
|---|---|
| 版 | 1.0（2026-10-29 正式版） |
| 言語名 / コンパイラ名 | AX65 / ax65 |
| 対象 | W65C02S を基本とする 6502 系 CPU を使った自作マシン |
| 文法 | Rust に寄せた文法。6502 に固有の機能だけを独自の書き方にする |
| 関連資料 | 『AX65 サンプルと効果測定 1.0』（`ax65_1.0/sample/ax65_sample_1.0.md`）：サンプルのプロジェクト一式、コンパイル結果、効果測定（要約は [付録D](#appD)） |
