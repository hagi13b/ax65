## 付録D サンプル「METEOR DODGE」（参考）

AX65 のサンプルのゲームです。詳細は別冊『AX65 サンプルと効果測定 1.0』（`ax65_1.0/sample/ax65_sample_1.0.md`）にあります。

| 項目 | 内容 |
|---|---|
| 内容 | 上から落ちてくる 8 個の隕石を、一番下のプレイヤーが左右に動いてよけるゲーム |
| ターゲット | v2（シリアル端末だけ。スコアを端末に表示）、v3（v2 に画面を追加。隕石とプレイヤーを画面に描く） |
| 操作 | A で左、D で右、Q で終了 |
| 測定のターゲット | v2（W65C02S、1MHz） |

### D.1 フォルダの構成

```
sample/project/
├── ax65.proj                    プロジェクトファイル（17.2節）
├── targets/
│   ├── v2.target                シリアル端末の構成
│   └── v3.target                v2 を引き継ぎ、画面を追加（extends）
├── src/
│   └── meteor.ax65              ゲームの本体（main を含む）
└── hw/
    ├── acia_console.ax65        impl console（ACIA）
    └── v3_screen.ax65           impl screen（v3 だけ）
```

### D.3 測定の結果

v2 のターゲットで 600 フレーム動かした結果です。「1 フレーム」は、送信待ちのない理想の条件での平均のサイクル数です。

| 段階 | 1 フレーム（サイクル） | コード（バイト） |
|---|---|---|
| `-O0` | 1016 | 581 |
| `-O1` | 808 | 433 |
| **`-O2`（既定）** | **740** | **386** |
| `-Os` | 729 | 426 |
| 手書きのアセンブリ | 724 | 313 |
| cc65 v2.18 `-Oirs -Cl --codesize 500`（同じゲームの C 版。cc65 の最速の設定。参考） | 2106 | 931 |

- AX65 の各段階のコンパイル結果は、この仕様書の規則に従って手で生成した想定出力です。
- 測定の方法、シリアル端末の条件での結果、考察は、別冊にあります。
