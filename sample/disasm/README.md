# disasm — 逆アセンブラ（Apple II の L コマンド風）

実機 v2 の上で動く W65C02S の逆アセンブラです。シリアル端末から番地を打つと、その番地から 20 命令を Apple II のモニタの `L` コマンドと同じ形で表示します。

## 動かし方

```sh
cd sample/disasm
ax65 build                      # build/v2/disasm.woz ができる
```

1. PC の端末ソフトを 19200bps・8N1 で USB シリアルにつなぐ
2. `build/v2/disasm.woz` を HEXMON で $0200 から打ち込み、`0200` → JMP で実行する
3. 端末に `AX65 DISASSEMBLER` とプロンプト `*` が出る

大きさは、コード 985 バイト＋定数 846 バイト（-O2）です。

## コマンド

プロンプト `*` に続けて打ち、Enter で実行します。

| 入力 | 動作 |
|---|---|
| `F800L` | F800 番地から 20 命令を表示する |
| `L` | 前回の続きから 20 命令を表示する（起動直後は $0200 から） |
| `300LL` | L を続けて書くと、その回数だけ続けて表示する |
| `Q` | HEXMON へ戻る |

- 番地は 1〜4 桁の 16 進です。5 桁以上打つと、最後の 4 桁が使われます（Apple II と同じ）。
- 小文字でも打てます。空白は無視します。1 行は 40 文字までです。
- バックスペース（BS・DEL）で 1 文字消せます。
- わからない文字や、番地だけでコマンドのない行には、ベルを鳴らして `?` を出します。

## 表示の形

```
3000-   00          BRK
3001-   01 3C       ORA   ($3C,X)
3009-   06 5F       ASL   $5F
300B-   07 66       RMB0  $66
3010-   0A          ASL
3012-   0C 89 BE    TSB   $BE89
301B-   0F 9E D3    BBR0  $9E,$2FF1
301E-   10 A5       BPL   $2FC5
3003-   02          ???
```

| 欄 | 内容 |
|---|---|
| 番地 | 4 桁の 16 進と `-`、その後に空白 3 個 |
| バイト | 命令のバイトを最大 3 個（`XX ` の 3 文字ずつ）、その後に空白 3 個。合わせて 12 文字 |
| 名前 | 3 文字。RMB・SMB・BBR・BBS はビットの番号を付けた 4 文字 |
| オペランド | 名前の欄を 6 文字にそろえた後に書く。オペランドのない命令は何も書かない |

オペランドの書き方：

| 番地の付け方 | 表示 | 番地の付け方 | 表示 |
|---|---|---|---|
| 即値 | `#$nn` | 間接 | `($nnnn)` |
| ゼロページ | `$nn` `$nn,X` `$nn,Y` | 間接（X） | `($nn,X)` |
| 絶対 | `$nnnn` `$nnnn,X` `$nnnn,Y` | 間接（Y） | `($nn),Y` |
| アキュムレータ | なし（`ASL`） | ゼロページ間接（65C02） | `($nn)` |
| 相対分岐 | 飛び先の番地 `$nnnn` | 絶対間接（X）（65C02 の JMP） | `($nnnn,X)` |
| BBR・BBS | `$nn,$nnnn`（ゼロページと飛び先） | | |

- 対象は W65C02S のすべての命令です（65C02 で増えた命令、RMB・SMB・BBR・BBS、WAI・STP を含む）。
- 未定義の命令は `???` と表示し、1 バイトとして扱います。
- $FFFF の次は $0000 に戻って続けます。

## 注意

- I/O の番地（$8000〜$88FF）を逆アセンブルすると、読んだだけで状態が変わる機器があります（UART の受信データ、HEXPAD のキーなど）。
- Apple II のモニタにある、番地だけを打ってメモリを見る機能や、`.` による範囲の指定はありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `src/disasm.ax65` | 本体（命令の表、表示、コマンドの処理） |
| `hw/acia_console.ax65` | console の実装（UART） |
| `hw/hexmon_keyboard.ax65` | keyboard の実装（v2.target が bind する。disasm では使わない） |
| `targets/v2.target` | 実機 v2 のターゲット定義 |

## テスト

```sh
cd sample
python3 -I tools/run_disasm.py disasm/build/v2/disasm.bin [端末の出力を書くファイル]
```

エミュレータ（`tools/sim65c02.py`）で disasm を動かし、UART からコマンドを打ち込みます。端末への出力を、スクリプトの中の参照用の逆アセンブラの出力と 1 文字ずつ比べます。試すのは、命令コード 256 個すべて、前向き・後ろ向きの分岐、$FFFF から $0000 への一周、5 桁の番地、小文字、バックスペース、まちがったコマンド、Q での終了です。

## 実装のメモ

- AX65 には整数を番地にする書き方がないので、ゼロページのポインタ `MEMP` に番地を入れるところ（`point_at`）だけをアセンブリで書いています。読み出しは言語の `MEMP[i]`（`lda (MEMP),y`）です。
- 命令の名前の表 `NAMES` は、コンパイル時に 1 文字目・2 文字目・3 文字目の 3 つの表に分けています。こうすると行の先頭の表が要らず、小さくなります。
- `list_one` には `#[inline(never)]` を付けています。ax65 1.1.0 では、`#[jump_table]` の `match` を含む関数を展開すると、アセンブルのときに表の飛び先の記号が見つからないエラーになるためです。
